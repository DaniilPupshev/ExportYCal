# Расписание → Яндекс.Календарь

Скрипт берёт расписание группы с сайта `rasp.dmami.ru` и создаёт события в Яндекс.Календаре.
Сначала можно запускать в безопасном режиме (ничего не записывает), а потом — с записью.

> Важно: **не публикуйте пароль приложения**. Если случайно отправили пароль кому‑то — сразу отзовите и создайте новый.

---

## Что делает скрипт
- Скачивает расписание группы.
- Преобразует расписание в события календаря.
- Добавляет события **один раз** с **еженедельным повторением** между датами `df` и `dt`.
- Длительность занятия — **90 минут**.
- В описании: **аудитория** + **тип занятия**.
- Пары с аудиториями `_Спортзал_` и `________ПД________` **не добавляются**.

---

## Быстрый старт (самый простой сценарий)

### 1) Подготовьте файл `.env`
```bash
cp .env.example .env
```
Откройте `.env` и заполните:
```
YANDEX_URL="CalDAV-ссылка"
YANDEX_LOGIN="логин@yandex.ru"
YANDEX_PASSWORD="пароль_приложения"
YANDEX_CALENDAR_NAME="Название календаря"
```

### 2) Запуск (сразу с записью в календарь)
```bash
bash run.sh
```

`run.sh` сам установит зависимости и запустит скрипт в режиме записи.

### 3) Тестовый запуск (ничего не записывает)
Если хотите сначала проверить данные:
```bash
pip install -r requirements.txt
python main.py
```

## Где взять переменные

### `YANDEX_LOGIN`
Это ваш логин Яндекса, обычно email.

### `YANDEX_PASSWORD`
Это **пароль приложения** для календаря (не обычный пароль от аккаунта):
- Откройте настройки безопасности Яндекс ID.
- Создайте пароль приложения для «Календарь / CalDAV».
- Скопируйте и сохраните.

### `YANDEX_URL`
CalDAV‑ссылка на календарь:
- Откройте Яндекс.Календарь.
- Наведите на нужный календарь → шестерёнка (настройки).
- Вкладка **Экспорт** → скопируйте **CalDAV URL**.

### `YANDEX_CALENDAR_NAME`
Название календаря, куда добавлять события.
Если не указать — скрипт возьмёт **первый календарь** в списке.

## Как устроено расписание (что важно знать)

В получаемых данных **нет времени начала пар**, есть только номер пары (1..7) и день недели (1..6).
Поэтому время начала задаётся в скрипте.

Сейчас использованы такие времена:
- 1 пара: 09:00–10:30  
- 2 пара: 10:40–12:10  
- 3 пара: 12:20–13:50  
- 4 пара: 14:30–16:00  
- 5 пара: 16:10–17:40

Если у вас другие времена — задайте их через переменную:
```
RASP_PAIR_TIMES="1=09:00,2=10:40,3=12:20,4=14:30,5=16:10"
```

---

## Полезные переменные

Можно задавать их в `.env`:

```
RASP_GROUP="241-161"          # Код группы
RASP_SESSION="0"              # Семестр
RASP_DRY_RUN="1"              # 1 = не писать в календарь, 0 = писать
RASP_PAIR_TIMES="1=09:00,2=10:40,3=12:20,4=14:30,5=16:10"
RASP_PAIR_DURATION_MIN="90"   # Длительность пары в минутах
```

## Что происходит при запуске

### Тестовый режим (`RASP_DRY_RUN=1`)
- Скачивает расписание.
- Сохраняет `rasp_raw.json`.
- Печатает несколько первых занятий.
- **Ничего не пишет** в календарь.

### Режим записи (`RASP_DRY_RUN=0`)
- Создаёт/обновляет события в календаре.
- Ставит недельное повторение до конца диапазона дат.

## Частые проблемы

### `Unauthorized` (401)
Причины:
- Неверный пароль приложения (или старый).
- Неверный CalDAV URL.

Решение:
1) Отозвать старый пароль приложения.
2) Создать новый пароль приложения.
3) Убедиться, что `YANDEX_URL` взят из настроек календаря.

### `404` или `500` при запросе расписания
Иногда сайт расписания отвечает ошибкой.
Решение:
- Подождать и повторить запуск.
- Убедиться, что группа указана верно.

## Что можно улучшить (оптимизация для пользователей)

Если хотите сделать запуск ещё проще:
1) **Скрипт выбора календаря**  
   При первом запуске показать список календарей и сохранить выбранный в `.env`.
2) **Проверка доступа**  
   Перед записью в календарь сделать проверку логина/пароля и вывести понятное сообщение.
3) **Вывод понятного списка занятий**  
   Показать таблицу: день, время, предмет, аудитория, тип.
